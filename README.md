# Electrospun Anodes in Sodium-Ion Batteries

Supplementary files associated with the master's thesis:

**"Electrospun anodes in Sodium-Ion batteries"**

by João Cavaco

Master's Degree in Physical Engineering  
Faculty of Sciences, University of Lisbon  
External research project at Aalborg University

## About

This repository contains supplementary files related to the development of
electrospun carbon-based materials for their application as anodes in
sodium-ion batteries.

The files currently provided in this repository consist of G-code used to
control the near-field electrospinning setup during the fabrication of
electrospun mats.

## G-code

The `G-code` folder contains the machine instructions used to control the
movement of the Creality CR-10S Pro 3D printer used as the near-field
electrospinning platform.

The G-code defines the movement of the needle in the X, Y and Z directions
and controls the deposition pattern used during the fabrication of the
electrospun mats.

The files were generated using Cura and subsequently adapted for the
near-field electrospinning setup.
